# Pravila za novosti SOLIDWORKS 2025 in agenčni kontrolni seznam

## Pravila za novosti SW 2025

**Ne ugibaj.** Samo potrjene novosti so vredne omembe.

- Če je novost **potrjena**: navedi kaj je novo, kako vpliva na workflow, dodaj povezavo na What's New 2025.
- Če novost **ni potrjena**: napiši točno besedilo: "Ni potrjene posebne novosti za SOLIDWORKS 2025 pri tej funkcionalnosti."
- Če je informacija odvisna od **licence**: napiši: "Razpoložljivost funkcije je lahko odvisna od licenčnega paketa. Preveriti je treba Product Matrix ali lokalno licenco."

What's New 2025: https://help.solidworks.com/2025/english/WhatsNew/c_wn2025_welcome.htm

## Agenčni kontrolni seznam

Preden zaključiš poglavje, preveri:

- [ ] Podtema ima slovenski naziv.
- [ ] Podtema ima angleški naziv.
- [ ] Naveden je modul.
- [ ] Naveden je tip dokumenta.
- [ ] Naveden je namen.
- [ ] Jasno je opisano, kdaj funkcijo uporabiti.
- [ ] Jasno je opisano, kdaj funkcije ne uporabiti.
- [ ] Navedena je lokacija v SOLIDWORKS.
- [ ] Navedeni so predpogoji.
- [ ] Navedeni so vhodni podatki.
- [ ] Opisan je osnovni postopek.
- [ ] Po potrebi je opisan napredni postopek.
- [ ] Razložene so glavne nastavitve.
- [ ] Dodan je praktični primer.
- [ ] Dodana je kontrola pravilnosti.
- [ ] Dodane so povezave z drugimi funkcijami.
- [ ] Dodane so pogoste napake in rešitve.
- [ ] Dodane so najboljše prakse.
- [ ] Dodane so omejitve (raven C).
- [ ] Preverjene so novosti za SOLIDWORKS 2025.
- [ ] Dodana je mini vaja.
- [ ] Dodan je kontrolni seznam.
- [ ] Dodane so povezave ali iskalni niz.
- [ ] Izključeni moduli niso obravnavani poglobljeno.
