# Predloga za celotno workbook poglavje

Uporabi samo, ko uporabnik zahteva workbook poglavje ali primerljivo učno gradivo.
Pri kratkih odgovorih in diagnostiki sledi SKILL.md. Oznake [A], [B] in [C]
nakazujejo možno globino poglavja; ne polni razdelkov brez vsebine samo zaradi
predloge. Če je potreben uredniško enoten workbook, dogovori zahtevane razdelke.

```
[ID] [SLOVENSKI NAZIV] / [ANGLEŠKI NAZIV]
```

## 8. Osnovni postopek uporabe [A]
Konkretni koraki (ne splošni):
1. Odpri ustrezen dokument.
2. Pripravi geometrijo ali izberi element.
3. Zaženi funkcijo.
4. Nastavi glavne parametre.
5. Potrdi funkcijo.
6. Preveri rezultat.
7. Shrani dokument, če je relevantno.

## 9. Napredni postopek uporabe [C]
Če je relevantno:
- Uporaba s konfiguracijami
- Uporaba z Design Tables
- Uporaba v sestavih / na risbah
- Povezava s CAM / Simulation / MBD / Inspection
- Vpliv na BOM ali cut list
- Vpliv na performance
